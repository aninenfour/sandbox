# FILE 020 · Gas 费：为什么转账要花钱（中文版）

```
你有没有遇到过这种事：转二十美元的币，手续费却要五十？你以为钱是给了银行，其实呢，你是在一场拍卖里，输了。

先说个背景。以太坊大概每十二秒出一个新区块，每个区块的空间都是有限的。Gas 说白了，就是你这笔交易要占多少空间，一笔最普通的转账，要用两万一千个单位。

那要是想上车的人比座位还多呢？那就变成拍卖了。你给每个单位报个价，区块从出价最高的开始往下装，出价太低的话，嗯，就只能等下一班了。

二零一七年，一款养卡通猫的游戏，叫加密猫，直接把整个网络堵死了，大概三万笔交易卡在那儿排队。还有二零二二年的一个晚上，一场 NFT 卖地活动挤爆了，买家光是 Gas 费，就烧掉了一亿五千多万美元。

出路是二层网络。Rollup 把几百笔交易打包，合成一笔，再提交上去。二零二四年那次升级之后，有些二层的手续费，只要几美分。

所以说，手续费不是税，是拍卖。你每按一次发送，就是这场拍卖里的一个出价人。下次付钱之前，先看看这条路，堵不堵。
```
