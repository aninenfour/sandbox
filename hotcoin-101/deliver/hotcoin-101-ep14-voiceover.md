# FILE 014 · Stablecoins, Explained

```
A stablecoin is basically a promise, one coin, one dollar, so the real question is who's promising.

The simplest kind is like a coat check. You hand over a dollar, the issuer keeps it, and you get a coin you can swap back.

Which makes the reserve the whole deal, because in March twenty twenty-three USDC had three point three billion stuck in a bank that failed, and the coin slipped under a dollar for days.

The second kind skips the bank. You lock up more crypto than you borrow, and if it falls too far, it gets sold first.

And the third kind is backed by, uhm, a formula. That was Terra's UST, and in May twenty twenty-two it broke, UST sank to about ten cents, and about forty-five billion in value was gone in a week.

So the peg is a claim, not a law, and a stablecoin's only as stable as what's standing behind it.
```
