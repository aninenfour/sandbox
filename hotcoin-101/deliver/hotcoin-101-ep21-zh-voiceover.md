# FILE 021 · 梭哈、跑路、赌狗（中文版）

```
币圈有一整套黑话：梭哈、跑路、赌狗。听着挺好笑，其实呢，大多是穿着笑话外衣的警告。

先说梭哈，英文叫 Ape in。就是不看白皮书，也不做功课，看别人都在冲，自己也闭着眼往里冲。

然后就是跑路，英文叫 Rug pull，抽地毯。项目方发个币，大家一窝蜂冲进去，然后项目方撤走流动性，或者直接砸盘，脚下的地毯，一下子就没了。

二零二一年，有个蹭《鱿鱼游戏》热度的代币，涨到两千多美元，买家却根本卖不出去。几分钟后直接归零，项目方卷走了大约三百万美元。同一年，Chainalysis 统计，跑路骗局占了所有加密诈骗收入的百分之三十七，超过二十八亿美元。

这也不是老黄历。二零二五年二月，一个叫 LIBRA 的代币，阿根廷总统发帖推荐之后，市值冲到四十亿美元，几小时内暴跌九成以上，内部钱包套现了大约一亿美元。

最后是赌狗，英文叫 Degen，就是 degenerate gambler，赌徒的意思。有意思的是，很多人还挺骄傲地这么叫自己。

一个圈子天天拿某种风险开玩笑，说明这个风险是真的。所以冲之前，先问一个问题：谁能抽走这块地毯？
```
