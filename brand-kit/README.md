# Hotcoin brand kit

Everything a designer or a Claude Project needs to make on-brand Hotcoin posters, slides and videos.

| File | What it is |
| --- | --- |
| [claude-project-instructions.md](claude-project-instructions.md) | Paste into a claude.ai Project. The rules, tokens, layouts and checks. |
| [prompts.md](prompts.md) | Poster brief, background art, mascot, slides and video prompts. |
| [templates/poster-4x5.html](templates/poster-4x5.html) | Poster template with tokens, components and the logo built in. Preview: [poster-4x5-preview.png](templates/poster-4x5-preview.png) |
| [logo/](logo/) | Official logo and symbol: PNG originals and SVG copies (traced from the PNGs, 99.7% pixel match). |
| [mascot/](mascot/) | The green 101 mascot: reference from the Hotcoin 101 videos, plus one approved generated scene. |
