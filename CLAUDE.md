# Hotcoin content studio: rules for Claude

This repo produces Hotcoin marketing content in code: videos (Remotion), carousels and posters (Playwright HTML renders),
plus ready-to-post copy for X, Instagram, LinkedIn, TikTok and Telegram. Read this file fully before making anything.

## 1. Non-negotiable content rules
- **No em dashes** in on-screen text or post copy. Use commas, periods, colons or "to" (e.g. "Nov 6 to 16").
- **Never fake a logo.** Coin logos come only from CoinGecko (`api.coingecko.com` → `image`). Exchange logos in a
  CoinMarketCap-style table may come from CMC's static exchange icons. Any other brand logo: official source only, or leave it out.
- **No real people's likeness implying endorsement** (no founder/celebrity photos or quotes on promos). Stock people only
  when anonymous (back view, face covered). Footage: only freely licensed or public domain (Unsplash, NASA, Prelinger/archive.org).
  Log every outside photo/footage in `hotcoin-tradfi/FOOTAGE_CREDITS.md`.
- **Never name competitors** in public copy (e.g. don't mention Binance or OKX, even when their news is relevant).
  Styles can be *inspired by* competitors, never copied.
- **Verify every number and claim** with a source before it goes on a graphic. Put the date of the data on the slide or in
  the post. Note sources in a comment at the top of the render script. If a fact is uncertain, say so to the user instead of guessing.
- **Keep text readable**: no overlaps, nothing cut off, nothing hidden behind 3D objects or UI. Check every render visually.
- **Risk lines**: futures, earn and price posts carry a short "Not financial advice" / "Futures trading is high risk" in the caption
  (on-graphic only if asked; the user dislikes tiny grey footer text on graphics).
- **Rewards wording**: always say what kind of reward it is: "futures fee voucher" vs "futures trial funds" vs "Earn trial funds".
  State when tiers don't stack.
- **Neutral on politics.** PolitiFi/election content is data only, no side-taking.

## 2. Brand
- Colours: ink `#0B0E11` / `#07090A`, lime `#B8F26A`, green `#7EC25A`, up `#2DBD85`, down `#F6465D`.
  Data posts use red `#E5484D` for losses and green `#17A86B` for gains.
- Logos: `hotcoin-tradfi/public/brand/logo-official-white.png`, `logo-official-black.png`, `symbol-official-white.png`.
- Fonts: Inter Tight (headlines/body), JetBrains Mono (labels, kickers, numbers), Instrument Serif italic (accent words),
  Noto Sans SC for Chinese (`public/fonts/NotoSansSC-*.ttf` from Google Fonts).
- Default sizes: carousels and X/IG feed 4:5 (1080x1350), banners/YouTube 16:9 (1920x1080), Reels/TikTok 9:16 only when asked.
  Render stills at 2x (deviceScaleFactor 2 / `--scale=2`).
- Languages: English first; Chinese (and sometimes Vietnamese) versions on request. Chinese sign-up links use `hotcoinv5.com`,
  English ones use `hotcoin.com`.

## 3. Styles the team approved (reuse these)
- **White data post** (best performer): white background, big red/green headline number, bold line plus grey second line,
  clean line/step chart, hairline table, faint halftone background art (e.g. Capitol, USDT coin).
  Examples: `social/events/2026-11-anniv9/usdt-post.mjs`, `hotcoin-tradfi/src/politifi/Wiped.tsx`, `social/reserve-oct29/render.mjs`.
- **Editorial carousel** with real-object photo cutouts (rembg) on warm off-white: `social/altseason/render.mjs`.
- **Dots / particle style** (Dan Koe-like): black, one field of dots morphing into numbers and logo, serif italic copy:
  `hotcoin-tradfi/src/anniv9/Anniv9Dots.tsx`.
- **3D coverflow** of glowing cards with a search-bar finale: `hotcoin-tradfi/src/sale/SaleFlow.tsx`.
- **16:9 split screen**: text panel left, 3D animation right, merged full-frame ending: `hotcoin-tradfi/src/earn/EarnWide.tsx`.
- **CoinMarketCap-style table** with our row lifting out: `hotcoin-tradfi/src/rank/CmcRank.tsx`.

## 4. What the team rejected (avoid)
- Rainbow / off-brand colour palettes; stay in ink, lime, green, white.
- Cluttered layouts with many competing elements; one hero per frame.
- Childish illustrations; prefer financial, numeric, clean.
- Tiny grey footer text and source lines on graphics (put sources in the caption or script comments).
- Text appearing on a blank first frame; frame 1 must already show the design.
- Cheesy emoji on graphics (e.g. clap emoji).
- Copying a reference too closely, or repeating the previous post's layout for a new one.

## 5. How to build and render
- Remotion project: `hotcoin-tradfi/`. Register compositions in `src/Root.tsx`.
  - Still: `npx remotion still src/index.ts <Id> out/x.png --scale=2 --log=error`
  - Video: `npx remotion render src/index.ts <Id> out/x.mp4 --codec=h264 --crf=17 --concurrency=4`
  - 3D (three.js) scenes need `--gl=swangle`. Run stills one at a time.
- HTML renders: `PW_PATH=$(npm root -g)/playwright node social/<topic>/render.mjs`.
- Music: original, generated by `hotcoin-tradfi/scripts/make-*-beat.py` (numpy + soundfile). No copyrighted tracks.
- Use system `/usr/bin/ffmpeg` for frame checks (Remotion's build lacks some filters).
- `public/*` asset folders and `out/` are gitignored; re-create assets with the scripts if missing.
- Data sources that work: CoinGecko (throttles; retry), CoinMarketCap data-api (`api.coinmarketcap.com/data-api/v3/...`),
  Binance public data (`data-api.binance.vision`), DefiLlama, DexScreener, Hotcoin public API (`api.hotcoinfin.com`).

## 6. Workflow
- Show the user a still or contact sheet and fix layout issues before rendering full videos.
- Always deliver the post copy with the graphic (X version, plus IG if asked), short and with tickers.
- Ask before using any paid/AI generation connector (Higgsfield, Canva AI) every time.
- Never ask for API keys in chat and never commit keys; keys go in environment settings.
- Commit and push finished work with a clear message.
