# Daily industry-data post (from Nov 29, 2026)

Owner brief (Nov 28): a separate daily section. One heavy, detailed visual with simple text, about industry data.
Formats inspired by viral posts (dense data table, 2x2 quadrant, hand-drawn flowchart, etc.). Always vary the style AND the topic.
The flowchart was used once as a GM (Nov 29); from now on these formats are for industry data only.

- Cadence: once per day, about 17:00 UTC+8 (vary a few minutes).
- Channels: X main "Hotcoin 🟩", Facebook "Hotcoin", LinkedIn "Hotcoin", Telegram "Hotcoin Announcements" (+2 min).
- Copy: simple text, short. X under 280. Date + source of data in the caption (not tiny text on the graphic).
  Price/market posts end with "Not financial advice." No competitor names. No em dashes.
- Data only from sources that work (CoinGecko, CMC data-api, DefiLlama, Binance public data, DexScreener). Verify every number.
- Logos: coins only from CoinGecko image URLs. No fake logos.
- Style rotation (do not repeat yesterday's): dense table, quadrant/scatter, hand-drawn flowchart or diagram on real data,
  ranked bars, heatmap grid, timeline, "then vs now" comparison, map, etc.
- Scripts: data-posts.mjs (table + quadrant), flowchart.mjs. Outputs in out/ (gitignored). Log each post in posted.md.
