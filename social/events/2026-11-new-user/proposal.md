## 零、预算申请（摘要）

本次申请一项**新用户拉新活动**预算。我们提供两个方案供选择：

| | 方案 A：不限名额 | 方案 B：首批 N 名（推荐 N = 300） |
|---|---|---|
| 名额 | 不设上限 | 前 100 / 300 / 500 / 1,000 名（按完成 KYC 先后） |
| 预算性质 | 按实际参与量浮动 | **固定上限** |
